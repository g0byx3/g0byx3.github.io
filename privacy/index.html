Privacy policy

Privacy policyLast updated 29 September 2026

tl;dr: I don't want your data.

Scope

This policy covers everything I publish as g0byx3: the Wear OS watch faces (Earth Orbit, Doomsday), whatever comes next, and this website. If a project ever works differently, its own page will say so.

Data

My projects do not collect, store, transmit or share personal data. No analytics, no advertising, no tracking, no accounts.

Watch faces

They are built with the Watch Face Format: no executable code and no network access. The watch draws them from a description file and a set of images.

To do so, it hands them the time, the time zone, the date and the settings you pick. Those values are only used to draw the face and never leave the watch.

This website

Static pages hosted on GitHub Pages, with fonts from Google Fonts. No cookies, no analytics. As with any web page, GitHub and Google see the requests your browser makes to them, including your IP address.

Changes

If a future project ever needs data, this page will say what, why and where it goes before that project ships.
