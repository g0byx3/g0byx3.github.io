Earth Orbit Watch

Privacy policy · Wear OS watch face · last updated 26 September 2026

tl;dr: nothing leaves your wrist.

Earth Orbit Watch (com.g0byx3.earthorbitwatch) is a watch face built with the Watch Face Format. It contains no executable code: the watch's own runtime draws it from a description file and a set of images.

Data

Earth Orbit Watch does not collect, store, transmit or share any data. It has no network access, no analytics, no advertising and no accounts.

What it reads on the watch

To draw the face, the Wear OS runtime supplies it with the current time, the time zone, the day of the year and the settings you choose. These values are used only to render the face on the screen and never leave the watch.
